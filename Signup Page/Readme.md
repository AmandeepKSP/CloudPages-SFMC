# Enjoy building your sign-up form

This project provides a **Newsletter Sign-Up** form with **AMPscript**. integration. The form validates emails, stores data, and provides a smooth user experience.

## How to Use:
* Copy and paste the code into your **Salesforce Marketing Cloud CloudPage**.
* Customize the form, styling, and logos.
